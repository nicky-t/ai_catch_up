# Gartner（ガートナー）

## 一言で
IT分野の調査・コンサルティング企業。「ハイプ・サイクル」（技術への期待度の推移を示す図）や企業調査を通じて、AI導入の「今どのフェーズにいるか」を測る定点観測役としてdailyで繰り返し登場する。

## 仕組み
- 技術への期待度の推移を「黎明期→過度な期待のピーク期→幻滅期→啓発期→安定期」の5段階で示す「ハイプ・サイクル」を毎年発表し、AI関連技術がどのフェーズにあるかを分析する（例：2026年版で「エージェンティックAI」が「過度な期待のピーク期」に進んだ、2026-09-08既報）
- CIO・技術責任者など数千人規模へのアンケート調査を定期的に実施し、「AI導入でIT部門の人員は減るか」「ベンダー主導のAIエージェント導入はどの程度放棄されるか」といった実務に直結する予測・統計を発表する
- 日本法人（Gartner Japan）は国内企業向けに、サイバー攻撃への緊急提言のような時事性の高いレポートも発表する

## 実務での使い方
- 導入検討中の技術が「過度な期待のピーク期」にあるかどうかを確認し、過大な期待値で導入判断をしていないかを点検する材料になる
- ベンダー主導の「Forward Deployed Engineering（FDE、顧客の現場に常駐して課題解決を支援する方式）」を契約する際は、Gartnerが提言する契約前・契約期間中・契約終了時の3段階チェック（知財の所有権明確化・自社人材への知見移転・内製化計画）を参考にできる
- 調査はアンケート・自己申告ベースのものが多く、母数・実施時期（調査時点とAI技術の進化速度のずれ）を確認したうえで引用する

## 講座で使うなら
- 30 秒説明: 「IT業界の調査会社です。新しい技術が『期待が高まりすぎている時期』なのか『実際に定着してきた時期』なのかを図や調査データで示してくれます」
- たとえ話: 新商品の流行り具合を定点観測する市場調査会社のような立ち位置。「話題になっている」ことと「実際に売れている」ことの違いを教えてくれる
- 演習案: 受講者の自社で導入中・検討中のAI技術を1つ挙げさせ、それが「期待のピーク期」「幻滅期」「安定期」のどこに近いと感じるかを議論させる

- 2026-10-25: 2026-10-08既報の「2028年までに企業の約70%がベンダー主導のFDEエージェントAIを放棄する」予測について、＠ITが実務向けの処方箋を解説。「FDEウォッシング」（個別対応を製品機能のように見せる）のリスクを指摘し、契約前（パートナー選定・知財の所有権明確化）・契約期間中（自社人材への知見移転）・契約終了時（内製化計画の実行）の3段階チェックを提言（[daily](../daily/2026-10-25.md) / [出典](https://atmarkit.itmedia.co.jp/ait/articles/2610/24/news006.html)）
- 2026-10-22: CIO・技術責任者約2,002人への調査（2026年5月実施）で、約40%が2027年にIT部門の人員増加を見込むと回答。「AI導入でIT人員は減る」という通念に反し、部門内ではサイバーセキュリティ・データ分析など一部職種が拡大し別の職種が縮小する「二重の変化」が起きていると説明。AIから「大きな・変革的な価値」を得たCIOは13%にとどまり、58%がコスト削減の圧力を感じていると回答（[daily](../daily/2026-10-22.md) / [threads/ai-productivity-employment](../threads/ai-productivity-employment.md) / [出典](https://www.itmedia.co.jp/enterprise/articles/2610/21/news030.html)）
- 2026-10-20: Gartner Japanが9月28日発表の「日本におけるクラウドとAIのハイプサイクル：2026年」を＠ITが報道。31のクラウド・AI関連技術を分析し、フロンティアAI・Forward Deployed Engineer（FDE）・エージェンティックAI・フィジカルAI・クラウドレジリエンスの5項目が「過度な期待」のピークにあると指摘（[daily](../daily/2026-10-20.md) / [出典](https://atmarkit.itmedia.co.jp/ait/articles/2610/19/news029.html)）
- 2026-10-18: 国内で2026年9月以降に重大な不正アクセスが相次いだことを踏まえ、日本企業向けの緊急提言を発表。2026年7月実施の調査では約30%の企業しか必要な対策を実施できておらず、AIエージェントの悪用で攻撃の速度・規模が拡大していると指摘。緊急パッチ適用・設定ミス修正・ログの遡及調査・個人情報漏えいの有無確認・委託先の対応状況確認など7項目を提言（[daily](../daily/2026-10-18.md) / [threads/ai-safety-regulation](../threads/ai-safety-regulation.md) / [出典](https://www.itmedia.co.jp/enterprise/articles/2610/16/news048.html)）
- 2026-10-08: ベンダーの「Forward-Deployed Engineering（FDE）」方式で構築された企業向けAIエージェントのうち、2028年までに70%が放棄されると予測。「FDEウォッシング」が技術面でなく構造面での失敗を招くと指摘し、正当なFDEの条件として「深い製品知識が必要な場面に限定」「顧客側への知見移転」「事前の撤退戦略の明確化」の3点を挙げた（[daily](../daily/2026-10-08.md)）
- 2026-09-14: 企業の85%が「AIでコスト削減できる」と考える一方、87%が「無駄なトークン消費」への懸念を抱えているという調査結果が、＠ITのトークン浪費対策記事で紹介された（[daily](../daily/2026-09-14.md) / [出典](https://atmarkit.itmedia.co.jp/ait/articles/2609/13/news005.html)）
- 2026-09-08: 「日本の未来志向インフラ技術ハイプ・サイクル」2026年版で、「エージェンティックAI」が2025年版の「黎明期」から「過度な期待のピーク期」へ進行。2025年版では言及されていなかった「フィジカルAI」も新たにピーク期に登場（[daily](../daily/2026-09-08.md)）
- 2026-08-20: 「推論のパラドックス（Inference Paradox）」という分析を公表。モデル1トークンあたりの単価は下がり続けるが、エージェント型AIは通常のチャットボットの5〜30倍のトークンを消費するため、エージェント型ワークフロー1件あたりの推論コストは2028年までに5倍以上に増加すると予測（[daily](../daily/2026-08-20.md)）
