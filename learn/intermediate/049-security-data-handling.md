# 049 セキュリティとデータ取り扱い：学習利用・保存・越境の論点

!!! abstract "この記事で説明できるようになること"
    - 「学習利用」「保存」「越境」の3つの論点を分けて説明できる
    - ベンダーの契約プラン（個人向け／企業向け）でデフォルトの扱いがどう違うかを比較できる
    - 導入時に確認すべきチェック項目を挙げられる

## 仕組み

AIサービスのデータ取り扱いは、実は1つの論点ではなく3つに分かれる。

1. **学習利用**：入力・出力がモデルの再学習（ファインチューニング含む）に使われるか
2. **保存**：会話ログやAPIリクエストがどこに・どれくらいの期間保存されるか
3. **越境**：データがどの国のサーバーで処理・保存され、海外の法制度（捜査機関のアクセス権など）の対象になりうるか

この3つは独立して決まる。「学習に使われない＝安全」ではなく、学習利用がオフでも保存期間が長ければ情報漏洩のリスクは残るし、保存期間が短くても越境先の法制度によっては開示命令の対象になりうる。

Anthropicの企業向け製品（API・Claude for Work等）を例にすると、デフォルトでは入力・出力は学習に使われない。学習に使われるのは、利用者が明示的にフィードバック（Rate chats機能など）を送った場合に限られ、その場合は整理前の会話全体を含むデータが5年間バックエンドに保管される。Team/Enterpriseプランの管理者は、組織設定で一般メンバーのフィードバック送信自体を無効化できる（出典: Anthropic Privacy Center、取得日 2026-10-06）。つまり「学習オフ」が既定でも、機能ひとつ（フィードバック送信）がオンのままだと、個別の利用者の操作で学習データ化しうるという構造になっている。

## 比較・判断基準

| 論点 | 確認すべき質問 |
|---|---|
| 学習利用 | デフォルトはどちらか。オプトイン／オプトアウトのどちらの設計か。個人向けプランと企業向けプランで方針が違うか |
| 保存期間 | 通常のログは何日保持されるか。不正利用検知・フィードバック経由のデータは別の（長い）期間が設定されていないか |
| 越境 | 処理サーバーのリージョンを選べるか。選べない場合、どの国の法制度の対象になるか |
| 契約形態 | 個人向け無料プランと企業契約（DPA＝データ処理契約）では保護水準が違う。業務利用は必ず企業契約を結ぶ |

判断基準は「自社の情報の機密度」と「契約で保証される水準」を照らし合わせること。機密度が高い業務（人事・医療・契約書など）ほど、デフォルト任せにせず契約書（DPA）の該当条項を確認する必要がある。

## 落とし穴

1. **「学習に使われない」と「漏洩しない」を同じ意味だと誤解する**：学習利用オフは再学習への流用を防ぐだけで、保存先のセキュリティ事故やアクセス権限ミスは別問題
2. **個人向け無料プランの方針を、業務利用にそのまま当てはめる**：多くのベンダーは個人向け無料プランと企業契約でデフォルトが異なる。無料プランの検証結果を業務導入の判断材料にしない
3. **「フィードバック機能」や「お気に入り登録」など、学習方針の例外になりうる個別機能を見落とす**：デフォルトの学習方針を確認しただけで安心し、個別機能の設定を見落とすケースが多い

## 実務への接続

- 導入前チェックリストに「学習利用のデフォルト」「保存期間」「処理リージョン」「DPAの有無」の4項目を必ず入れる
- 機密度が高い業務では、契約でゼロデータリテンション（処理後即時削除）を選べるプランを優先する
- 社内ガイドライン（学習050で扱う）には、「どの機密度のデータをどのプランで扱ってよいか」の対応表を含めると実務で使いやすい

## 講座で使うなら

- 30 秒説明: 「AIにデータを渡すときの不安は『学習に使われる』『いつまでも保存される』『海外に置かれる』の3つに分けて考えると整理できます」
- たとえ話: 郵便物を渡すときの「開封して内容を覚えられるか（学習利用）」「いつまで保管されるか（保存）」「どの国の郵便局を経由するか（越境）」の3つの不安を分けて考えるのと同じ
- 演習案: 受講者の業務で実際に使っているAIサービスについて、上の比較表の4項目を契約書・利用規約から実際に探させてみる
