# Anthropicの新規株式公開（anthropic-ipo）

## 何の流れか
AnthropicがSECへのS-1提出（2026年10月27日）からIPO実現までの一連の流れを追うストーリーライン。資金調達・企業統治・財務内容の開示を通じて、AI企業の「高成長・高投資・高損失」という決算構造を講座の材料にするための索引。

## 現在地（最新の要約）
<!-- 新規作成時に 3〜5 行で埋める。以後は週次 agent が更新 -->
- 2026年11月19日（米国時間）、Nasdaq Global Select Market（ティッカー「ANT」）に上場。IPO価格83ドルから初値111.50ドル前後まで上昇（約34%高）、時価総額は初値水準で2兆ドル超に達しApple・Amazon・Alphabet・NVIDIA・Microsoftに次ぐ規模になった
- 11月20日にIPOの最終引受完了（オーバーアロットメント全行使）を発表。発行済み株式11億2,700万株・1株83ドルで、IPO単独の調達額は約935億ドル、私募増資（260億ドル）と合わせた総額は約1,195億ドルに確定。創業者7人はそれぞれ約2.8億ドル（合計約19.5億ドル）を売却したとTechCrunchが分析し、公益ファンド・従業員寄付等を合算すると最大1,560億ドルの慈善資金が生まれうるとの推計も出た（この1,560億ドルは複数の仮定を積み上げた推計であり、調達額・株数等の確定情報とは区別して扱う必要がある）
- 11月17日にAmazon・Googleとの大型出資契約の詳細を開示。IPO後の保有比率は両社合計「ほぼ30%」（いずれも議決権なし株式）に達し、クラウド大手が出資者と計算資源の買い手を同時に兼ねる構造が明確になった
- 2026年10月27日のSEC正式提出（S-1）、11月4日の修正版提出、11月10日のIPO価格帯確定・ロードショー開始を経て、11月19日の上場・11月20日の最終引受完了まで約1カ月で完結した
- 創業者7人は議決権付きClass F株で51.1%の投票権を維持。競合OpenAIも同時期に評価額1.25兆ドルでの資金調達を進めており、両社の規模・財務内容の比較が今後も講座ネタになる

## 論点・見立て
- 「売上は急成長しているが純損失も同時に拡大している」という決算構造は、他のAI企業（OpenAI等）にも共通しており、投資家がどこまで許容するかが上場後の株価を左右する
- 創業者が議決権を集中させる「スーパー議決権株」構造は、MetaやSnapと同様の設計で、上場後も創業者主導の経営を維持する狙いがある
