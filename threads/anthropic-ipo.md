# Anthropicの新規株式公開（anthropic-ipo）

## 何の流れか
AnthropicがSECへのS-1提出（2026年10月27日）からIPO実現までの一連の流れを追うストーリーライン。資金調達・企業統治・財務内容の開示を通じて、AI企業の「高成長・高投資・高損失」という決算構造を講座の材料にするための索引。

## 現在地（最新の要約）
<!-- 新規作成時に 3〜5 行で埋める。以後は週次 agent が更新 -->
- 2026年10月27日にSECへS-1を正式提出（上半期売上163億ドル・純損失807億ドル）、10月28日にその詳細（社内コードの9割超をClaudeが書いた等）が判明
- 11月4日に修正版S-1提出（7〜9月期売上169億5,600万ドル）、11月10日にIPO価格帯（1株70〜78ドル・想定時価総額最大1.404兆ドル）が確定しロードショーが始まった
- 創業者7人は1人あたり約2.5億ドルを売却する一方、議決権付きClass F株で51.1%の投票権を維持。ナスダック上場は11月19日前後を予定（ティッカー「ANT」）
- 競合OpenAIも同時期に評価額1.25兆ドルでの資金調達を進めており、両社の規模・財務内容の比較が今後の講座ネタになる

## 経緯
<!-- agent が日付順に追記。新しいものを上に -->
- 2026-11-11（記載日）: 11月10日、IPO価格帯を1株70〜78ドルに設定しロードショーを開始。想定時価総額は上限価格で1.404兆ドル、発行株式数8億2,500万株。AMD・Broadcom・Google・Micron・Microsoft・Nvidia・TSMCが計260億ドル分の無議決権株（Class N）を私募購入（Google・Nvidiaは各100億ドル）。創業者7人はそれぞれ約338万株を売却し中間価格では1人約2.5億ドルを手にする。3四半期累計売上332億ドル・純損失1,040億ドル、インフラ関連の将来支出約束総額約900.9億ドルも開示。ナスダック上場は11月19日前後の見込み（ティッカー「ANT」）（[daily](../daily/2026-11-11.md) / [topics/anthropic](../topics/anthropic.md) / [出典](https://www.anthropic.com/news/roadshow-launch)）
- 2026-11-04: 修正版S-1を提出。2026年7〜9月期の売上高は169億5,600万ドル（前四半期比約47%増）、1〜9月累計は332億4,200万ドル。1〜9月の純損失は1,040億3,900万ドルに拡大（主因はSAFE等の公正価値変動という非現金損失）。インフラ関連の将来支出約束総額は約8,954億ドル（[daily](../daily/2026-11-04.md) / [出典](https://www.itmedia.co.jp/news/article/2611/03/2000002831/)）
- 2026-10-28: 提出済みS-1の内容が判明。9月のソースコード追加・変更の90％超をClaudeが記述、エンジニアの役割は監督役に変化。社内Claude利用額は1〜9月で250倍超、従業員数は9月末約5,300人（1年で2.7倍）。リスク説明は90ページ超に及び人類の存亡リスクにも言及（[daily](../daily/2026-10-28.md) / [出典](https://www.itmedia.co.jp/news/article/2610/27/2000002644/)）
- 2026-10-27: 米SECにIPO申請（Form S-1）を正式提出。上場先はNasdaq Global Select Market、ティッカーは「ANT」。2026年上半期売上163億ドル、純損失807億ドル（主因は非現金の会計調整）。創業者7人の「Founder LLC」が議決権50.1%を保持（[daily](../daily/2026-10-27.md) / [出典](https://www.anthropic.com/news/s1-sec)）

## 論点・見立て
- 「売上は急成長しているが純損失も同時に拡大している」という決算構造は、他のAI企業（OpenAI等）にも共通しており、投資家がどこまで許容するかが上場後の株価を左右する
- 創業者が議決権を集中させる「スーパー議決権株」構造は、MetaやSnapと同様の設計で、上場後も創業者主導の経営を維持する狙いがある
