### :red_circle: OpenAI、脆弱性発見・防御パッチ作成に特化したサイバーセキュリティモデル「GPT-6 Cyber」を発表（重要）
<!-- importance: high | tags: [openai, safety] -->
<div class="chips" markdown>**タグ:** `openai` `safety`</div>

OpenAIは11月5日、脆弱性の発見・検証や修正パッチの作成を行うサイバーセキュリティ特化モデル「GPT-6 Cyber」を発表した。提供対象はサイバーセキュリティプログラム「Daybreak」の最上位ティア「Daybreak Red」の審査済み利用者（運転免許証等でのID確認が必要）に限定される。関連する脆弱性調査の一環として、Linuxカーネルで948件・Firefoxで81件の新規脆弱性発見に取り組み、Linuxのバグ探索には約120万ドルを投じたという。記事は、攻撃側が「ガードレールを除去したオープンウェイトモデル」を無制限に使える一方、防御側のモデルは審査制限下にあるという非対称性を指摘している。
実務への影響：脆弱性管理の速度競争が攻守双方でAIを前提にする段階に入り、自社の脆弱性対応フロー（公表から対応までの時間）の見直しが一段と急務になる。

!!! tip "講師目線"
    攻撃と防御の非対称性（攻撃側は無制限、防御側は審査制限）を具体的な数字（948件・81件・120万ドル）で示せる好材料。受講者に自社の脆弱性対応フロー（公表から対応までの時間）を確認させる演習に使える。

<!-- importance: medium | tags: [anthropic, productivity] -->
<div class="chips" markdown>**タグ:** `anthropic` `productivity`</div>

### :hammer_and_wrench: vercel-labs/agent-desktop — スクリーンショット無しでAIエージェントにデスクトップ操作を許可するCLI
<div class="chips" markdown>**タグ:** `agent` `mcp`</div>

**できること**：macOS・Windows・LinuxのOSアクセシビリティツリーを読み取り、操作可能な要素にref（参照ID）を付けたJSONを返すCLI。エージェントはrefを指定してクリック・入力し、再度読み取って結果を確認するループを自分で回す。スクリーンショットやピクセルマッチングを使わないため軽量・高速。
**試し方**：`npm install -g agent-desktop`（Homebrewも可）でインストールし、`agent-desktop snapshot --app <アプリ名> -i`で操作可能な要素を取得、`agent-desktop click @<snapshot_id>:<ref>`のように操作する。`agent-desktop mcp`でMCPサーバーとしても起動できる。
**注意**：スナップショットやクリップボードの内容に非公開のデスクトップ情報が含まれるため公開ログ・アップロードへの混入に注意。macOSはアクセシビリティ権限の付与が必要（`agent-desktop permissions --guide`）。

### :hammer_and_wrench: max-sixty/worktrunk — 並列AIエージェント向けに設計されたGit worktree管理CLI
<div class="chips" markdown>**タグ:** `claude-code` `agent`</div>

**できること**：ブランチ名でGit worktreeを作成・切替・削除できるCLI。複数のAIエージェントを並行して走らせる際に作業ディレクトリを分けて変更の衝突を防ぎ、`wt list`で各エージェントの進捗・差分を一覧できる。
**試し方**：`brew install worktrunk && wt config shell install`でインストールし、`wt switch -x claude -c feature-a -- '指示文'`のようにworktreeの作成とClaude Code等のエージェント起動を1コマンドで行える。完了後は`wt merge main`でsquash・rebase・マージ・片付けを一括実行。
**注意**：Windowsでは`wt`コマンドがWindows Terminalと衝突するため`git-wt`を使う必要がある。ビルドキャッシュ共有はAPFS・btrfs・XFSなど対応ファイルシステムに限られる。
